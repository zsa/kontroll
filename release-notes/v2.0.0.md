- Kontroll talks to the keyboard directly. Keymapp is no longer needed.
- Support for the Wireless Voyager over Bluetooth.
- `--keyboard <INDEX>` picks the keyboard on any command (see `kontroll list`). `connect`, `connect-any` and `disconnect` now do nothing.
- `--port` is ignored.
- New `kontroll upgrade` command updates Kontroll itself. `kontroll upgrade --check` only reports whether a newer version exists.
- Windows and macOS builds are now signed.
