# Kontroll Examples

## Snake

Using macroquad to create simple snake game for your voyager keyboard.
Run the example by running this command:

```bash
cargo run --release --example snake
```

## Voyager dot clock

A shell script that shows the time on a Voyager's LEDs with the `kontroll`
CLI. See [its README](voyager_dot_clock_with_background/README.md).
